## 计划接法

```text
2S电池现有分线
├─ 原舵机DC供电线 → Hub电源输入 → 左腿／右腿／头颈三支路
└─ UBEC 5.0V → X5

X5 USB → 微雪Type-C（B档）
微雪总线接口 → Hub：只接信号和GND，VCC不接
Hub三路 → 各支路首只HD1910M：信号／VCC／GND完整连接
```

本计划以USB/B档通信为基础。微雪逻辑供电方式、Hub实际端子定义及额定总电流在到货后按实物与厂家资料复核；不把“8口”视为已证明能承受15只舵机的运动峰值。不能仅凭线色或插头能插入认定针序正确。舵机电源从Hub进入，不让15只舵机电流经过微雪至Hub的通信短线。2S电压不直接进入X5的5V输入。

到货后先核对端子针序和供电路径，再做三支路只读及带载验证。当前BOM不承诺已消除通信错误，也不等同于行走稳定性验收。[本轮进度](../progress/2026-11-06/README.md)
